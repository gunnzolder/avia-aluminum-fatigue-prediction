# Файли звіту

🇬🇧 [English version](README.md)

Усе в цій директорії (окрім двох README) **генерується** командою
`uv run python pipeline.py all` і може бути видалене та перебудоване будь-коли.
Ця сторінка пояснює, як обчислюються результати і що містить кожен файл.

## Як працює розрахунок

1. **Конвертація.** Оцифрований довідник росту тріщин розбирається в охайну таблицю
   точок (ΔK, da/dN). Метадані сплав/термообробка/орієнтація відновлюються із
   заголовків графіків, вбудованих у файл; опубліковані в довіднику коефіцієнти
   NASGRO/Walker зчитуються для перехресної перевірки.
2. **Валідація.** Точки мають задовольняти ΔK > 0, da/dN > 0 і фізичне обмеження
   **Kmax = ΔK/(1−R) ≤ 200 ksi·√in**, da/dN ≤ 0,1 in/cycle. Порушення вилучаються та
   фіксуються у звіті — це помилки оцифрування джерела, а не реальні вимірювання.
3. **Фітинг.** Кожна експериментальна крива (одна комбінація сплав/орієнтація/R)
   фітується рівнянням Періса **da/dN = C·(ΔK)ᵐ** методом найменших квадратів у
   лог-лог координатах. Приграничні ділянки (поріг / швидке руйнування), що
   відхиляються від степеневого закону, відсікаються ітеративно, поки покращується r².
4. **Тренування.** Три моделі — гребенева регресія (Ridge), Random Forest, SVR (RBF) —
   вивчають відображення *статичні властивості сплаву (Ftu, Fty, Fcy, Fsu, видовження,
   густина, E, G, ν) + R-відношення + серія/орієнтація → (log₁₀C, m)*. Оцінювання за
   трьома схемами крос-валідації: random K-fold, group K-fold за фізичним
   експериментом та **leave-one-alloy-out (LOAO)** — чесний тест прогнозування сплаву,
   відсутнього в тренуванні.
5. **Прогноз.** Для кожного цільового сплаву (див. `targets.yaml`) моделі прогнозують
   (C, m) за заданих R-відношень. Невизначеність — смуга розкиду q05–q95: квантилі по
   деревах для Random Forest, bootstrap-перенавчання для Ridge/SVR. Це оцінка розкиду,
   а **не** калібрований довірчий інтервал.
6. **Фізичний аудит.** Вхідні дані та прогнози перевіряються на додатність,
   монотонність da/dN відносно ΔK і правдоподібність показника Періса для алюмінієвих
   сплавів (PASS / WARN / FAIL). Криві з FAIL виключаються з тренування; прогнози з
   FAIL показуються, а не приховуються.

> Прогнозні криві — дослідницькі результати, а не сертифікаційні значення.

## Довідник файлів

| Файл | Вміст |
|---|---|
| `data_quality.txt` | Журнал конвертації: кількість рядків у таблицях, пропуски за колонками, видалені дублікати та перелік фізично неможливих точок із зазначенням сторінок джерела. |
| `coverage_matrix.csv` | Один рядок на сплав: `n_static_props` (кількість властивостей міцності), `n_material_variants` (варіанти матеріалу в AI-Ready), `n_cg_points` / `n_cg_curves` / `n_cg_datasets` (дані росту тріщини), `cg_R_min/max` і `cg_dK_min/max` (експериментальні діапазони), `n_sn_points` / `n_sn_kt` (втомні дані S-N), `n_dt_points` (дані живучості). Сплави зі статичними властивостями, але без кривих — цільові для прогнозу. |
| `fit_crosscheck.csv` | Наш показник Періса `m` для кожної кривої проти опублікованого в довіднику `ref_n` з тієї самої сторінки, з відхиленням `m_vs_ref_n_pct`. Порівняння лише орієнтовне: значення довідника належать формам NASGRO/Walker, зафітованим по всій кривій, наші — лише ділянці Періса. |
| `metrics.csv` | Метрики крос-валідації: один рядок на (схема × модель × ціль) із `r2`, `mae`, `rmse`. Цілі — `log10_C` та `m`. Порівняйте схеми, щоб побачити, наскільки задача невідомого сплаву складніша за інтерполяцію. |
| `predictions.xlsx` | Аркуш **predictions** — рядок на (цільовий сплав × R × модель): `log10_C_pred`, `m_pred`, `C_pred` (= 10^log10_C), `dK_applicable_min/max` (діапазон ΔK, у якому прогноз вважається чинним — медіанний діапазон фітів тренувальних кривих тієї ж серії) та межі інтервалів `q05/q95` для кожної цілі. Аркуш **training_fits** — усі зафітовані тренувальні криві з C, m, r², діапазоном ΔK, кількістю точок і ознакою придатності для тренування. |
| `ai_ready_dataset.xlsx` | Конвертований датасет у багатоаркушевій структурі AI-Ready: `materials`, `mechanical_properties` (довгий формат), `physical_properties`, `fatigue_data` (точки S-N), `DT_Data`, а також нові аркуші `crack_growth_points` і `figures_metadata`, створені в цьому проєкті. |
| `figures/paris_<сплав>_R<r>.png` | Прогнозна крива Періса для цільового сплаву та R-відношення: три криві моделей зі смугами розкиду q05–q95, лог-лог осі, побудовано в межах чинного діапазону ΔK. |
| `figures/loao_log10_C.png`, `figures/loao_m.png` | Leave-one-alloy-out «прогноз проти факту» для кожної моделі. Точки біля пунктирної діагоналі = добрий прогноз поза тренувальним сплавом. |
| `figures/coverage_matrix.png` | Теплокарта на основі `coverage_matrix.csv`. |

## Відтворення

```bash
uv run python pipeline.py all      # перебудувати все в цій директорії
uv run python pipeline.py export   # переекспортувати лише таблиці/рисунки
```
