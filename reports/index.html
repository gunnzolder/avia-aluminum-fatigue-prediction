Model validation Валідація моделей

Leave-one-alloy-out: each alloy is predicted by models that never saw it. Random Forest is the only model with positive skill on unseen alloys (R² ≈ 0.29 for log₁₀C); a random split flatters everyone (R² ≈ 0.78) — the gap is itself a key finding. Full numbers in metrics.csv. Leave-one-alloy-out: кожен сплав прогнозують моделі, що його не бачили. Лише Random Forest має додатну прогностичну здатність на невідомих сплавах (R² ≈ 0,29 для log₁₀C); random split лестить усім (R² ≈ 0,78) — сам цей розрив є ключовим висновком. How the calculation works Як працює розрахунок

  1. Convert. The digitized crack-growth handbook is parsed into a tidy table of (ΔK, da/dN) points; alloy metadata is recovered from chart titles embedded in the workbook, and the book's own NASGRO/Walker coefficients are harvested for cross-checking. Конвертація. Оцифрований довідник розбирається в охайну таблицю точок (ΔK, da/dN); метадані сплавів відновлюються із заголовків графіків у файлі, а опубліковані коефіцієнти NASGRO/Walker зчитуються для перехресної перевірки.
  2. Validate. Points must satisfy ΔK > 0, da/dN > 0 and the physical bound Kmax = ΔK/(1−R) ≤ 200 ksi·√in; violations (source digitization errors) are excluded and reported. Валідація. Точки мають задовольняти ΔK > 0, da/dN > 0 і фізичне обмеження Kmax = ΔK/(1−R) ≤ 200 ksi·√in; порушення (помилки оцифрування джерела) вилучаються та фіксуються.
  3. Fit. Each experimental curve is fitted to the Paris law da/dN = C·(ΔK)ᵐ by log-log least squares, iteratively trimming near-threshold and fast-fracture tails. Фітинг. Кожна крива фітується рівнянням Періса da/dN = C·(ΔK)ᵐ методом найменших квадратів у лог-лог координатах з ітеративним відсіканням приграничних ділянок.
  4. Train. Ridge, Random Forest, and SVR learn (log₁₀C, m) from alloy static properties + R ratio, evaluated by random, group, and leave-one-alloy-out cross-validation. Тренування. Ridge, Random Forest і SVR вивчають (log₁₀C, m) зі статичних властивостей сплаву + R-відношення; оцінювання — random, group та leave-one-alloy-out крос-валідація.
  5. Predict. Models predict (C, m) for each target alloy at the requested R ratios; uncertainty is a q05–q95 spread band (per-tree quantiles / bootstrap), not a calibrated confidence interval. Прогноз. Моделі прогнозують (C, m) для кожного цільового сплаву за заданих R-відношень; невизначеність — смуга розкиду q05–q95 (квантилі по деревах / bootstrap), не калібрований довірчий інтервал.
  6. Physics audit. Inputs and predictions are checked for positivity, monotonicity, and Paris-exponent plausibility (PASS / WARN / FAIL); failed curves are excluded from training. Фізичний аудит. Вхідні дані та прогнози перевіряються на додатність, монотонність і правдоподібність показника Періса (PASS / WARN / FAIL); криві з FAIL виключаються з тренування.
